# Project Context — Clevora
- **Produk:** Clevora (bukan Quicky). Jangan pernah menggunakan "Quicky" sebagai nama aplikasi pada kode, UI, namespace, maupun dokumentasi baru.
- **Tujuan:** Aplikasi produktivitas penyiapan pesan WhatsApp (template, kategori, favorit, placeholder `{{...}}`, composer + live preview, formatting, word/char counter, click-to-chat URL generator, AI assist, lampiran Azure Blob Storage, dan mobile offline-first).
- **Larangan Produk:** Dilarang membuat WhatsApp inbox, membaca chat/kontak WhatsApp, auto-send, bulk messaging otomatis, atau integrasi WhatsApp tidak resmi.
- **Proteksi Workspace:** Jangan menghapus atau menimpa `Clevora.txt`, `mcp.json`, maupun direktori `quicky-html-chat-template/`.
