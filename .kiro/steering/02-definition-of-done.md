# Definition of Done — Clevora
Suatu fitur atau task hanya dianggap selesai apabila memenuhi seluruh kriteria berikut:
1. Tidak ada placeholder screen, fake success response, maupun komentar `TODO` pada fitur P0.
2. Tidak ada hardcoded secrets atau kredensial di dalam kode maupun konfigurasi publik.
3. Unit test, integration test, atau API/mobile test yang relevan telah ditulis dan lulus dieksekusi.
4. Build proyek terkait bersih tanpa error.
5. Progres nyata dicatat di `docs/IMPLEMENTATION-LOG.md` berdasarkan bukti perintah yang benar-benar dijalankan.
